# What's New

## v0.1.0 — Initial Release

**Content**
- TypeScript subject with 155 questions across 6 topics: Basics, Interfaces & Types, Functions, Generics, Classes, Advanced Types
- Java subject with 175 questions across 6 topics: Core Java, OOP, Collections, Concurrency, Java 8+ Features, Streams & Functional
- Python subject with questions covering Core Python, Data Structures, OOP, Functional Programming, Async, and Standard Library

**Features**
- Study mode: browse questions by topic with explanations and key concepts
- Interview simulation: timed quiz sessions with automatic scoring
- Results review: per-question breakdown with correct/incorrect indicators
- Progress tracking: per-topic completion rates and correct answer rates
- Bookmarks: save and review questions for later
- Font size control: 8 levels from XS to 4XL
- Dark and light themes
- Popup and full-tab modes
- Expandable popup width (480px → 800px)
- Offline-first: works without internet after installation

**Technical**
- Chrome Extension Manifest V3
- All data stored locally in IndexedDB via Dexie.js
- No account, no tracking, no external requests
