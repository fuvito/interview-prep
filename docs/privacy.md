# Privacy Policy

_Last updated: 2026-10-30_

## Summary

InterviewPrep does not collect, transmit, or share any personal data. Everything stays on your device.

## Data We Store

InterviewPrep stores the following data **locally in your browser's IndexedDB**:

- Question progress (which questions you attempted and whether you answered correctly)
- Interview session history and scores
- Bookmarked questions
- User preferences (theme, font size, last selected subject)

This data never leaves your device. There are no servers, no accounts, and no network requests of any kind.

## Data We Do Not Collect

- No personal information (name, email, location, etc.)
- No usage analytics or telemetry
- No crash reports
- No advertising identifiers

## Third-Party Services

InterviewPrep makes no requests to third-party services. It operates entirely offline after installation.

## Data Removal

You can delete all stored data at any time:

- **Progress**: Progress screen → Reset all progress
- **Bookmarks**: Remove individual bookmarks from the Bookmarks tab
- **All extension data**: Go to Chrome Settings → Privacy and security → Site data → Search for the extension and clear its storage

Uninstalling the extension also removes all locally stored data.

## Open Source

InterviewPrep is open source (MIT License). You can inspect exactly what the extension does at the source code level.
